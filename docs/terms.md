## 2. What the App Does

The app adds a **"Tap the Sign"** post-menu action. Using it posts a "tap the sign" image comment on the post. If the post contains LaTeX math, it also posts a locked, distinguished reply with that math converted to Unicode. Each post can be tapped only once while the app is installed.
